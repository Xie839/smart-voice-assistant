# VoiceFlow AI 智能语音助手

VoiceFlow AI 是一个基于 Qt 的 Windows 智能语音助手，面向实时语音输入和本地音频转写场景，目标是帮助用户通过语音快速生成可编辑文本，并支持后续的离线文本整理和在线 AI 智能优化。

## 当前进度

当前版本已完成 Qt Windows 桌面端主界面模块，包括：

- 左侧导航栏：实时语音输入、本地文件转写、历史记录、设置
- 实时语音输入主页面布局
- 识别模型选择：tiny 极速模式、base 均衡模式、small 高准确模式
- 文本处理模式选择：仅识别、离线优化
- 当前词库选择：通用词库、编程词库、学术词库、自定义词库
- AI 配置状态显示
- 原始识别文本与优化后文本双文本区域
- 开始输入、停止、选择文件、复制、导出、保存、清空、AI 智能优化等基础按钮
- 为后续麦克风输入、VAD 分句、语音识别、文本优化等模块预留信号接口

## 技术栈

- C++17
- Qt 6.8.3
- Qt Widgets
- CMake
- MinGW 64-bit
